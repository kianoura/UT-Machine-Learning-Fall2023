# Machine Learning — University of Tehran (Spring 2024)

This repository contains coursework, mathematical derivations, and Python implementations from the **Machine Learning** course offered at the **University of Tehran** in Spring 2024.

The assignments cover fundamental machine learning concepts, combining theoretical foundations, mathematical analysis, and practical implementations.

### HW1 — Bayesian Decision Theory and Classification

The first assignment focuses on probabilistic approaches to classification and parameter estimation.

**Key topics:**
- Bayesian decision theory and minimum-risk classification
- Cauchy, Rayleigh, Gaussian, and Poisson distributions
- Decision boundaries and classification error analysis
- Maximum Likelihood Estimation (MLE) and Maximum A Posteriori (MAP) estimation
- Naive Bayes implementation from scratch and comparison with Scikit-learn
- Classification of lung cancer and phishing datasets
- Image classification using handcrafted color-based features
- Model evaluation using accuracy, precision, recall, and confusion matrices

**Assignment materials:** [HW1 Directory](./HW1)
