# Homework 1 — Bayesian Decision Theory and Classification

**Course:** Machine Learning  
**University:** University of Tehran  
**Semester:** Spring 2024

## Overview

This assignment explores the mathematical foundations of Bayesian classification, decision theory, and probabilistic parameter estimation, along with practical applications of machine learning algorithms.

The homework consists of eight questions covering theoretical derivations, decision boundary analysis, probabilistic modeling, and Python-based implementations.

## Assignment Contents

| Question | Topic | Description |
|---|---|---|
| Q1 | Cauchy Distribution | Bayesian classification, decision boundaries, minimum error probability, and risk-sensitive classification |
| Q2 | Bayesian Decision Theory | Minimum-risk decision rules with nonzero diagonal loss values |
| Q3 | Rayleigh Distribution | Derivation of Bayesian decision boundaries |
| Q4 | Gaussian Classification | Analysis of decision boundaries under unequal class priors |
| Q5 | Gaussian Discriminant Analysis | Mean and covariance estimation, decision boundaries, and classification risk |
| Q6 | MLE & MAP Estimation | Poisson likelihood, Gamma prior, posterior distribution, and parameter estimation |
| Q7 | Naive Bayes Classification | From-scratch implementation and Scikit-learn comparison using lung cancer and phishing datasets |
| Q8 | Image Classification | Cloudy vs. sunset sky classification using handcrafted image features |

## Key Concepts

- Bayesian Decision Theory and Minimum Risk Classification
- Probability Distributions: Cauchy, Rayleigh, Gaussian, and Poisson
- Maximum Likelihood Estimation (MLE)
- Maximum A Posteriori (MAP) Estimation
- Naive Bayes Classification
- Decision Boundaries and Classification Errors
- Feature Extraction and Image Classification
- Model Evaluation: Accuracy, Precision, Recall, and Confusion Matrix
